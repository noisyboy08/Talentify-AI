## 🚀 Quick Start Guide



### ⚡ Prerequisites



```bash

✅ Node.js 16+

✅ npm / yarn / pnpm

✅ Modern Browser

✅ Internet Connection

```



### 🛠️ Installation & Setup



```bash

# Clone the repository

git clone https://github.com/yourusername/talentify-ai-resume-analyzer.git

cd talentify-ai-resume-analyzer-main



# Install dependencies

npm install



# Start development server

npm run dev

```



🎉 **App Running:** http://localhost:5173  

🌐 **AI Ready:** Claude Sonnet 4 integration active



### 🎯 Getting Started



1. **Upload Your Resume**

   - Navigate to `/upload`

   - Upload PDF or image format

   - Resume is automatically analyzed



2. **View Analysis**

   - See comprehensive scoring

   - Review multi-dimensional analysis

   - Check ATS compatibility



3. **Optimize Your Resume**

   - Use AI Auto-Rewrite for sections

   - Tailor for specific roles

   - Enhance projects with metrics

   - Compare with job descriptions



4. **Track Progress**

   - Save multiple versions

   - Monitor score improvements

   - Generate portfolios

   - Prepare for interviews
